# Emily Pizza · Menú digital

Carta digital de Emily Pizza (Candelaria La Nueva, Ciudad Bolívar, Bogotá) para armar pedidos personalizados y enviarlos por WhatsApp.

- Sitio estático: `index.html` + carpeta `img/`. Sin dependencias ni build.
- Para desplegar en Vercel: importar el repo, sin configuración adicional.
- Datos editables al inicio del script en `CONFIG` (WhatsApp, QR de Nequi y Bre-B, horario, favoritos, mapa).
